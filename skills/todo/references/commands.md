# Todo 命令参考

完整的命令列表和行为说明。

## 添加类

| 命令 | 行为 |
|------|------|
| `添加任务: XXX` | 分析后添加到 Todo 区 |
| `添加重要任务: XXX` | 分析后添加到 重要 区 |
| `新任务: XXX` | 分析后添加到 Todo 区 |
| `记录任务: XXX` | 分析后添加到 Todo 区 |
| `记录待办: XXX` | 分析后添加到 Todo 区 |
| `管理任务: XXX` | 分析后添加到 Todo 区 |

## 完成类

| 命令 | 行为 |
|------|------|
| `完成任务: XXX` | 标记完成，移到 Finish，加日期 |
| `标记完成: XXX` | 标记完成，移到 Finish，加日期 |
| `done: XXX` | 标记完成，移到 Finish，加日期 |
| `finish: XXX` | 标记完成，移到 Finish，加日期 |

## 移动类

| 命令 | 行为 |
|------|------|
| `移到重要: XXX` | 移动到 重要 区 |
| `移到todo: XXX` | 移动到 Todo 区 |
| `提升优先级: XXX` | 移动到 重要 区 |
| `降级优先级: XXX` | 移动到 Todo 区 |

## 查看类

| 命令 | 行为 |
|------|------|
| `查看所有任务` | 显示全部任务 |
| `查看重要任务` | 显示 重要 区 |
| `查看未完成任务` | 显示未完成的 |
| `查看已完成` | 显示 Finish 区 |
| `show todos` | 显示全部 |
| `list todos` | 列出全部 |

## 删除类

| 命令 | 行为 |
|------|------|
| `删除任务: XXX` | 删除指定任务 |
| `remove todo: XXX` | 删除指定任务 |
