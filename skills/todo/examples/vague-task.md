# 场景2: 模糊任务询问细节

## 用户输入

```
添加任务: 优化系统
```

## AI 推理过程

**分析**:
- 任务描述过于模糊 ❌
- 不知道具体要优化什么
- 无法直接执行

**问题**:
1. 优化哪个部分？（性能/安全/架构/数据库）
2. 当前有什么具体问题？
3. 期望达到什么效果？

## AI 响应

```
"优化系统"这个任务不够具体。请问：
1. 要优化哪个部分？（性能/安全/架构/数据库）
2. 当前有什么具体问题？
3. 期望达到什么效果？

请提供更多细节，我会帮你转为具体可执行的任务。
```

## 用户补充

```
数据库查询太慢，需要优化查询性能
```

## AI 二次推理

**分析**:
- 现在清晰了 ✅
- 具体目标：优化数据库查询性能
- 可执行

**判断**:
- 包含"优化"、"性能"关键词
- 是否紧急？需要询问优先级

## AI 询问优先级

```
明白了。这个任务放【重要】还是【Todo】？
```

## 用户选择

```
重要
```

## AI 最终响应

```
已添加到【重要】:
- [ ] 优化数据库查询性能
```

## 结果

通过两次询问，将模糊任务转为清晰、可执行的任务，并确定了优先级。
